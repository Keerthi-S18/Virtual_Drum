# 🥁 Virtual Drum

## 📌 Project Description

Virtual Drum is a Python-based project that allows users to play virtual drums using an orange pen and a webcam.

The system detects the movement of the orange pen and produces different drum sounds based on its position.

## 🚀 Features

* Real-time orange pen detection
* Webcam-based interaction
* Three virtual drum zones
* Different sounds for each zone
* Score tracking
* High-score display
* Interactive drum-hit animation

## 🛠️ Technologies Used

* Python
* OpenCV
* NumPy
* Pygame
* SciPy

## ▶️ How to Run

1. Install the required libraries:

```bash
pip install opencv-python pygame-ce numpy scipy
```

2. Run the project:

```bash
python play_video.py
```

3. Use an orange pen in front of the webcam to play the virtual drums.
